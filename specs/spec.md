# Специфікація каталогу навчальних відео — уточнення 2026-11-01
## Межі й контракт
Поля введення: title, topic — непорожні рядки до 200 символів; duration_minutes — строго ціле 1..1440, bool не допускається. Зайві поля заборонені. Запис отримує UUID id. Сховище — список у пам'яті, новий процес починає порожнім; одна копія Uvicorn. Дублікати дозволені як окремі записи. GET повертає порядок створення.
POST /videos: JSON трьох полів → 201, об'єкт із id; неправильні поля → 422. GET /videos → 200, масив записів. POST /videos/ai: {text: непорожній рядок до 2000} → 201, та сама форма запису; відмова → {detail:{status,reason}}, 422 (needs_clarification, invalid_proposal, semantic_mismatch) або 503 (model_unavailable). Відмова не змінює кількість чи вміст жодного запису. Ручні помилки 422 мають стандартний detail FastAPI.
## AI-контракт і зміст
Модель повертає JSON з трьома полями або null. Схема перевіряється сервером. Підтримані повідомлення: «Відео НАЗВА, тема ТЕМА, тривалість N хвилин»; також «Урок …; тема …; тривалість …» та «Назва: …; тема: …; тривалість: … хв». Регістр маркерів неважливий. Назва й тема повинні дослівно відповідати явним полям після обрізання пробілів; тривалість — явному числу. Інші формулювання, кілька тривалостей, відсутні поля: 422 needs_clarification без виклику моделі. Консервативне обмеження навмисне: не вгадуємо неоднозначні дані. Модель не має доступу до сховища. При null — needs_clarification; неправильний JSON/тип/діапазон — invalid_proposal; правильна схема з підміненою тривалістю/назвою/темою — semantic_mismatch. Ліміт виклику провайдера 15 секунд, повторів 0; помилка/timeout/відсутній ключ →503. Ручний шлях незалежний навіть без ключа.
## Контрольована заміна
AI_MODE=live (типово): Groq, GROQ_MODEL=openai/gpt-oss-20b, ключ лише в .env сервера. AI_MODE=fixture: фіксовані відповіді всередині AI-адаптера; title FixtureInvalid → duration_minutes='15'; FixtureWrong → правильна схема, duration=21 замість12; FixtureDown → імітований збій; FixtureNull → null; інші підтримані повідомлення → явно витягнуті поля. Маркери працюють лише в локальному fixture-режимі. HTTP API не має параметрів обходу перевірок. Один і той самий шлях валідації/збереження для обох режимів.

## Розширення: вільні речення
Для текстів поза шаблоном AI сам виділяє назву й тему дослівними фрагментами повідомлення. Сервер приймає лише одну явну додатну тривалість у хвилинах цифрами, відхиляє альтернативи та перевіряє входження обох текстових полів. Це перевірка опори на текст, а не гарантія правильного розуміння ролей полів. Старий явний шаблон зберігає точне порівняння. Додати тести довгого речення, вигаданих полів і неоднозначності.
